# Завдання 2: інтеграл методом Монте-Карло

**Функція:** f(x) = x²  
**Межі інтегрування:** [0, 2]  
**Аналітичне значення:** ∫₀² x² dx = x³/3 |₀² = **8/3 ≈ 2.66666667**

## Метод Монте-Карло

На інтервалі [a, b] генеруються N випадкових точок xᵢ, далі:

∫ₐᵇ f(x) dx ≈ (b − a) · (1/N) · Σ f(xᵢ)

Реалізація: `monte_carlo_integral` у `task2.py`.

## Порівняння результатів (N = 100 000)

| Метод | Значення |
|-------|----------|
| Monte Carlo | 2.67095040 |
| Аналітично (8/3) | 2.66666667 |
| scipy.integrate.quad | 2.66666667 (оцінка похибки ≈ 2.96e-14) |

| Різниця | Значення |
|---------|----------|
| \|MC − аналітично\| | 0.00428374 |
| \|MC − quad\| | 0.00428374 |
| \|quad − аналітично\| | 0.00000000 |

## Залежність від N

| N | MC | \|MC − 8/3\| |
|---|-----|--------------|
| 1 000 | 2.656984 | 0.009683 |
| 10 000 | 2.641543 | 0.025124 |
| 100 000 | 2.670950 | 0.004284 |
| 1 000 000 | 2.666695 | 0.000028 |

При N = 1 000 000 похибка MC ≈ 0.00003 — результат дуже близький до точного 8/3.

## Висновки

1. **Метод Монте-Карло** коректно наближає площу під графіком f(x) = x² на [0, 2]. Значення MC (2.671 при N=100 000) близьке до точного інтеграла 8/3 (2.667).

2. **Аналітичне обчислення та `quad`** повністю збігаються (різниця ≈ 0). Це еталон для перевірки MC.

3. **Похибка MC** — випадкова; при збільшенні N вона зазвичай зменшується (на N=1 000 000 |MC − 8/3| ≈ 2.8×10⁻⁵). Окремі запуски з меншим N можуть тимчасово дати більшу похибку (наприклад N=10 000 у цьому експерименті).

4. **Практичний висновок:** MC підходить для наближення інтегралів, особливо складних або багатовимірних; для простих задач `quad` точніший і швидший. Наші розрахунки підтверджують правильність реалізації MC порівнянням з аналітикою та SciPy.
