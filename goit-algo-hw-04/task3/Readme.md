## Задача

Python має дві вбудовані функції сортування: sorted і sort. Функції сортування Python використовують Timsort — гібридний алгоритм сортування, що поєднує в собі сортування злиттям і сортування вставками.

Порівняйте три алгоритми сортування: злиттям, вставками та Timsort за часом виконання. Аналіз повинен бути підтверджений емпіричними даними, отриманими шляхом тестування алгоритмів на різних наборах даних. Емпірично перевірте теоретичні оцінки складності алгоритмів, наприклад, сортуванням на великих масивах. Для заміру часу виконання алгоритмів використовуйте модуль timeit.

Покажіть, що поєднання сортування злиттям і сортування вставками робить алгоритм Timsort набагато ефективнішим, і саме з цієї причини програмісти, в більшості випадків, використовують вбудовані в Python алгоритми, а не кодують самі. Зробіть висновки.

## Мета

Емпірично порівняти **сортування злиттям** (реалізація в `task3.py`), **сортування вставками** та **Timsort** (функція `sorted()` у CPython) за часом виконання на різних наборах даних, перевірити узгодженість із теоретичними оцінками складності та пояснити практичну перевагу вбудованого сортування.

## Теоретичні оцінки

| Алгоритм        | Найгірший випадок | Середній випадок | Кращий випадок (типовий) |
|-----------------|-------------------|-------------------|---------------------------|
| Вставками       | \(O(n^2)\)        | \(O(n^2)\)        | \(O(n)\) (вже відсортований масив) |
| Злиттям         | \(O(n \log n)\)   | \(O(n \log n)\)   | \(O(n \log n)\)           |
| Timsort         | \(O(n \log n)\)   | \(O(n \log n)\)   | \(O(n)\) при вже відсортованих або «майже відсортованих» даних |

Емпіричні заміри з timeit показують, що сортування вставками на великих випадкових масивах різко сповільнюється через квадратичну складність, тоді як злиття залишається прийнятним завдяки O(nlogn).

На вже відсортованих або майже відсортованих даних вставки та Timsort працюють набагато швидше, ніж «сліпе» рекурсивне злиття половин, бо використовують уже наявний порядок (короткі прогони та вставки на малих ділянках).

Повноцінний Timsort у Python реалізований на C і додатково оптимізований, тому sorted / list.sort зазвичай швидші за навчальні реалізації на чистому Python — саме тому на практиці користуються вбудованими функціями.
